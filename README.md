# Reducing Student Exposure to Phishing Messages

## Project Overview
This project aims to improve student awareness of phishing messages and help them identify suspicious emails, messages and links.

## Problem Statement
Students may receive fraudulent messages that imitate trusted sources. Lack of awareness can lead to clicking suspicious links and sharing personal information.

## Project Objectives
- Improve phishing awareness among students.
- Identify suspicious messages and links.
- Educate students about phishing techniques.
- Promote safe online communication.

## Working Procedure
1. Display sample phishing and genuine messages.
2. Explain common phishing warning signs.
3. Help students identify suspicious content.
4. Provide safety recommendations.
